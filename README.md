# Galgah

Landing page menu Galgah Drinks — Strawberry Milk, Matcha Latte, Thai Tea, Oreo Milk, dan es krim Vanilla & Matcha Signature.

Live: https://galgahrikui-dev.github.io/

## Struktur

- `index.html` — halaman utama (HTML, CSS, JS dalam satu file; animasi pakai GSAP dari cdnjs)
- `assets/img/` — foto produk (WebP)
- `.nojekyll` — GitHub Pages sajikan file apa adanya, tanpa Jekyll

## Deploy

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)`.
